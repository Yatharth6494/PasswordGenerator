# Password Generator

A sleek, responsive, and interactive Password Generator web application built using HTML, CSS, and vanilla JavaScript. This tool allows users to generate secure, randomized passwords based on customizable criteria such as length and character types.

## Features

* **Dynamic Length Slider:** Choose a password length between 1 and 20 characters. The slider track dynamically fills with color up to the thumb position.
* **Customizable Criteria:** Toggle checkboxes to include Uppercase Letters, Lowercase Letters, Numbers, and Symbols.
* **Strength Indicator:** A visual circular indicator that shifts color (Green/Yellow/Red) based on the strength and complexity of the generated password.
* **One-Click Copy:** Copy the generated password directly to your clipboard with an animated custom tooltip showing confirmation.
* **Fully Responsive Layout:** Designed with a vibrant dark-mode theme utilizing modern CSS Flexbox layout principles.

## Tech Stack

* **Frontend:** HTML5, CSS3 (Modern UI layout & custom form styling)
* **Fonts & Icons:** Google Fonts (League Spartan), Font Awesome Icons
* **Scripting:** Vanilla JavaScript (ES6+)
